## 📌 Sobre o Projeto & História de Origem

O **DataVerse** é um minicurso prático e estruturado de **Linguagem Python**, desenvolvido inteiramente em **Jupyter Notebooks**, com foco em fundamentos da programação, lógica de dados e projetos práticos.

### 💡 Como surgiu a ideia?
Após passar alguns meses lecionando aulas de **Excel do Básico ao Avançado** como fonte de renda alternativa, percebi o impacto positivo de transmitir conhecimento técnico de forma simples e direta. Essa vivência na docência acendeu o desejo de dar um passo além: criar uma série de materiais didáticos e gravar um **minicurso prático de Python**. 

O objetivo principal deste repositório é servir tanto como material didático e de apoio para quem está aprendendo quanto como um **projeto de portfólio profissional**, consolidando meu domínio técnico em lógica de programação, estrutura de código e capacidade Didática/Data Storytelling.

## 📂 Estrutura dos Módulos e Notebooks

O repositório está organizado em uma sequência lógica contendo **11 Notebooks numerados** que cobrem desde os conceitos iniciais até a construção de um projeto prático completo:

```text
data_verse/
├── 01_guia_e_estrutura.ipynb         # Guia e visão geral da jornada do minicurso
├── 02_introducao_ao_python.ipynb     # O que é Python, Jupyter e o primeiro print()
├── 03_variaveis_e_tipos_de_dados.ipynb # Variáveis, padrão snake_case, tipos primitivos e casting
├── 04_entrada_de_dados_e_operadores.ipynb # Função input(), operadores aritméticos e precedência
├── 05_estruturas_condicionais.ipynb  # Lógica booleana, indentação e estruturas if/elif/else
├── 06_listas_e_tuplas.ipynb          # Sequências ordenadas, mutabilidade vs imutabilidade
├── 07_dicionarios_e_conjuntos.ipynb  # Estruturas Chave-Valor e Sets para dados únicos
├── 08_estruturas_de_repeticao.ipynb  # Loops for, while, range(), break e continue
├── 09_funcoes_e_modularizacao.ipynb  # Princípio DRY, criação de funções (def) e escopo
├── 10_manipulacao_de_strings.
```

## 💻 Como Utilizar os Notebooks

### Pré-requisitos
Para rodar os arquivos localmente em sua máquina, você precisará ter o Python instalado ou o ambiente do VS Code configurado com a extensão do Jupyter.

### Passo a Passo

1. Clone o repositório:
   bash ,   git clone https://github.com/SEU_USUARIO/data_verse.git ,   

2. Acesse a pasta do projeto:
   bash ,   cd data_verse ,   

3. Abra os Notebooks:
   * No VS Code: Basta clicar em qualquer arquivo .ipynb com as extensões do Python/Jupyter instaladas.
   * Via Jupyter Lab / Notebook:
     bash ,     jupyter notebook ,
